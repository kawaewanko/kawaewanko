## 🐶 はじめに

こんにちは、**kawaewanko** です！

犬が好きで、ものづくりが好きな開発者です。日々の学びや経験を活かして、便利で楽しいものを作っていきたいと思っています。まだまだ成長中ですが、これからの活動を一緒に見守ってもらえるとうれしいです。

- 🛠️ **作りながら学ぶ：** 手を動かして試し、学んだことを次の改善につなげます。
- 🌱 **少しずつ前進：** 小さな一歩を積み重ねていきます。
- 🐾 **こだわりと遊び心：** 技術には真剣に、楽しむ気持ちも大切に。

## 🎯 これからやりたいこと

- Webアプリや便利なツールの開発
- 学んだことや開発の工夫を共有する
- 犬と暮らす日常をもっと楽しくするものづくり
