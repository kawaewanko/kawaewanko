## ものづくりの軸

- 🛠️ **作りながら学ぶ** — 手を動かし、試した結果を次の改善に活かします
- 🌱 **小さく育てる** — アイデアを、使える形まで少しずつ育てます
- 🐾 **真剣に、楽しく** — 技術へのこだわりと遊び心を両立します
